云境香藏

云境香藏是一个以传统藏香文化为基础，尝试将非遗文化与数字技术相结合的大学生创新创业项目。本仓库主要用于展示项目的前端网站和数字化定制功能原型。项目希望通过更加年轻化、互动化的方式，让更多人了解传统藏香文化，同时探索非遗产品在数字化设计、个性化定制和线上销售等方面的可能性。

目前网站主要包含首页、3D定制、香文化、在线购买、会员中心和联系我们等页面。其中，数字藏香工坊是网站重点展示的部分，用户可以了解不同香材，并根据个人喜好选择产品的外观设计。网站加入了星座、MBTI人格以及IP主题等定制元素，可以通过点击不同主题切换产品预览图片，让传统藏香与年轻人熟悉的文化元素结合起来。此外，网站还展示了线香、香牌、香丸、香盒等产品，以及藏香制作工艺和相关文化内容。

技术实现

网站主要使用 HTML、CSS 和 JavaScript 开发，整体采用静态网页结构。HTML 用于构建页面内容，CSS 负责网站的视觉设计、排版和响应式布局，JavaScript 主要用于实现导航菜单、主题切换、产品图片预览以及部分页面交互功能。

在项目结构上，index.html 是网站首页，studio.html 主要负责数字藏香工坊和个性化定制展示，culture.html 用于介绍藏香文化，shop.html 展示相关产品，member.html 和 contact.html 分别用于会员服务介绍和项目联系。网站的整体样式保存在 styles.css 中，部分通用交互逻辑由 script.js 实现，定制页面还使用了 JavaScript 完成主题内容的动态生成与切换。

目前网站中的3D定制区域主要通过图片切换展示不同的产品设计效果，尚未接入完整的实时三维建模系统。AI智能推荐、在线交易及会员管理等功能也仍有进一步开发和完善的空间。

运行方式

下载项目代码后，直接使用浏览器打开 index.html 即可查看网站，也可以在 VS Code 中使用 Live Server 插件进行本地预览。项目目前不需要配置数据库或安装额外依赖。

开发说明

云境香藏是我参与大学生创新创业项目过程中进行的一次网站开发实践，目前项目已获得大学生创新创业训练计划立项。在网站开发过程中，我尝试将项目计划书中的产品理念转化为实际的网页设计，并围绕数字藏香定制这一特色功能进行页面搭建和交互设计。

由于自己还处于编程学习阶段，开发过程中也借助了 AI 工具辅助代码编写、页面样式调整和部分交互功能的调试，再根据项目的实际需求对网站进行修改和整合。这次实践让我对前端网站的开发过程有了更具体的认识，也积累了一些将项目创意转化为网页原型的经验。

目前本仓库主要用于创新创业项目展示、功能原型验证和个人学习交流，部分功能仍处于演示阶段，后续会根据项目推进情况继续完善。
